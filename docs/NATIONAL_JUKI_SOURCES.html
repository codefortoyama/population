全国タブの2015年・2020年は、国勢調査（10月1日）に最も近い各市公表の住民基本台帳人口を使う（2026-10-20追加調査）。値は tools/build_national_oct.mjs に入れてあり、data/national.json の juki と jukiDate に反映される。2010年は従来どおり2011-03-31（総務省）。秋田市・山形市・高松市は2015・2020・2025年とも同時点の公表がなく、和歌山市は2015・2020年のみ同時点の住基月別がないため、翌年1月1日（2016/2021/2026-01-01）のまま。

検証

  • 各値は総務省「住民基本台帳に基づく人口」の翌年1月1日値と比べ、すべて±0.25%以内（3か月分の変動として妥当）。桁違い・推計人口の取り違えがないことを確認した。
  • 東京23区は東京都「住民基本台帳による世帯と人口（毎月）」の区部。区別23行の合計と区部が一致することを確認（2015年9,190,237／2020年9,585,007）。
  • 京都市は町別CSVの単純合計が京北地域を欠くため、市の長期時系列（市計）を使った。
  • 名古屋市は全市計がないため16区の合計。
