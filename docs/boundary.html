国勢調査と住基の「区域のずれ」について

富山市人口ビューアーの注記（区域ずれ?）の説明

結論

国勢調査の「町丁・字等」と、住民基本台帳（住基）の「通称町丁」は、名称が同じでも区域（範囲）が完全には一致しないことがあります。 本サイトで「区域ずれ?」と表示した町は、名称は一致しているものの人口差が大きく、区域のずれ、または施設・集合住宅などによる実差の可能性がある町です。 差の数値を「そのまま人口の差」と断定せず、確認のうえでお使いください。

対象：25町（対応1232町のうち、名称一致かつ差の絶対値200人以上）。一覧は boundary_candidates.csv を参照してください。

なぜずれるのか

  • 区域のずれ：国勢調査は「町丁・字等」（統計上の区画）、住基は市が運用する「通称町丁」で、区画の改名・分割・合併・飛び地の扱いが異なることがあります。
  • 施設・寮・病院：学生寮、社宅、病院、介護施設などは、住基と国勢で区域や計上先が異なることがあります。
  • 新しい住宅・開発：宅地造成やマンション建設で区域や人口が短期間で変わります。国勢調査は5年ごとのため、時期により差が出ます。
  • 時期差・外国人の扱い：国勢調査は10月1日、住基は9月末（本サイトの対応表は各年の9月末）です。また外国人を含むかどうかの扱いが異なる年があります。

どう判定したか

  1. 住基の町丁名と国勢の町丁・字等の名称を突合（表記ゆれ：ヶ/ケ、全角数字、丁目、舘/館、ノ/之 などを吸収）。
  2. 名称が一致した町のうち、差の絶対値が 200人以上 のものを「区域ずれ?」として注記。
  3. 大字（親区画）と丁目（子区画）の両方が対応する場合は、二重計上を避けるため親区画から子区画分を差し引いて比較（「調整」）。子区画の一部が未対応の場合は比較対象外（「対象外」）。
  4. 同名の別地区に計上されている場合は、近い方に割り当て（「別地区」）。

件数の目安（対応1232町中、名称一致）：|差|200人以上＝25町、300人以上＝13町、400人以上＝6町、500人以上＝3町。 親子の二重計上は0町（すべて残差調整済み）。

注記の種類（注列）

表示意味
区域ずれ?名称は一致するが差が大きく、区域のずれ等の可能性がある（本ページの対象）。
調整親区画から対応済みの子区画分を差し引いて比較している。
対象外子区画の一部が対応できず、比較できない（数値は非表示）。
別地区同名称の別地区に計上されている（近い方へ割当）。
※集約（町名・地区）に、何らかの注記付き町が含まれる。

見分け方の目安

  • 同じ大字の中の丁目どうしで差が相殺していれば、区域の付け替え（境界変更）の可能性が高い。
  • 大字全体で住基が多い/少ない場合は、施設・寮・新築などの実差、または区画のずれが疑われる。
  • 差率が非常に大きい小規模町は、1棟の施設・マンションの有無で大きく動くため注意。

区域のずれを確定するには、国勢調査の「町丁・字等境界データ」と住基の町丁区域を重ね合わせて確認する必要があります。
