全国タブ（47地点）

  • 国勢：e-Stat（tools/build_national.py、2010/2015/2020/2025。2025年は確定値）。
  • 住基：2015/2020/2025年は各市公式サイトの9月末・10月1日現在（2015/2020年は43地点、2025年は44地点）。秋田市・山形市・高松市は3年とも、和歌山市は2015/2020年のみ同時点の値がなく翌年1月1日。2010年は2011-03-31。東京23区は東京都「住民基本台帳による世帯と人口（毎月）」の区部（＝23区合計）。
  • 2015/2020年の採用値・出典：docs/NATIONAL_JUKI_SOURCES.md。2025年の入手可否・URL：docs/JUKI_OCT_SOURCES.md。取り込みは node tools/build_national_oct.mjs（data/national.json の jukiDate、dashboard.html の NATIONAL、data/students.js を更新）。
  • ランディングページ（index.html）の47地点比較と富山市の長期系列は、node tools/build_landing.mjs で data/landing.js に生成（元データは data/national.json と dashboard.html）。

2025年国勢調査

  • 年齢の2025年確定値は、2026-09-29公表の人口等基本集計（確定値・原数値）で取得済み（C6/C9）。
  • 小地域集計（町丁・字等）の2025年確定値は未公表（そのため町丁別2025は住基のみ）。

全国 国勢×住基タブ（46道府県の県庁所在地＋東京23区）

  • 東京は23区をまとめた「特別区部」（13100）。国勢は13100の行、住基は区別の行（13101〜13123）を合計。2015〜2025年の国勢値は2015年第1表・2025年表1-1確定（2020組替列）から取得（APIキー不要）。
  • 国勢調査（各年10月1日、市区町村別人口総数）: 2015=e-Stat API 0003149040（cdCat01=00710, cdCat02=010）、2020=0003445078、2025=0004065881（いずれもcdCat01=0）。
  • 住基（国勢の翌年1月1日、総務省「住民基本台帳に基づく人口、人口動態及び世帯数」・市区町村別【総計】）:国勢2015→2016年1月1日 statInfId=000031430150、2020→2021年 000040306659、2025→2026年 000040479049（e-Stat ファイルダウンロード https://www.e-stat.go.jp/stat-search/file-download?statInfId=...&fileKind=0）。
  • 2010年：国勢＝人口等基本集計 第2表（CSV statInfId=000012460663&fileKind=1、APIキー不要。熊本市は旧コード43201）、住基＝2011年3月31日 000011437958（1月1日基準は2014年から）。2012年7月以前の住基は日本人のみで、国勢（総人口）とは外国人の分だけずれる。
  • 差＝国勢(10/1)−住基(翌年1/1)（このタブのみ。概要タブは住基−国勢）。住基の10/1値は全国一律では公表されないため、最も近く春の転居期をまたがない翌年1/1を採用（約3か月のずれを含む）。グラフは全都市共通スケール。
  • 生データは data/raw/national/（未追跡）。生成は tools/build_national.py。
  • 検証は tools/verify_national.py：住基の市名・年齢別ファイル総数との一致、国勢の2015年第1表（2010組替つき）・2025年表1-1確定（2020組替つき）との一致、埋め込み配列との一致を全47地点×4年で確認（2026-10-16時点で不一致0）。松江市2010は2011-08の東出雲町編入前の境域（国勢・住基とも編入前で整合）。金沢市・大阪市2026-01-01の住基は男+女が計より1〜2人少ない（公表値どおり）。

tools/build_towns.py（町丁合計・年齢・性別）、tools/build_censustown.py（国勢町丁・境界修正）、tools/build_towns15.py（2015年住基・将来用）。再現手順は各スクリプトの冒頭コメント参照。
