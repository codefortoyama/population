国勢小地域と住基通称町丁は区域が一致しない場合がある。tools/build_censustown.py で以下を適用し、結果を data/censustown.js＋CENSUS_FLAG に格納。

ルール

  • dup：同一国勢キーに複数町が対応 → 住基値が最も近い町に計上、他は対象外（null＋注記）
  • adj：親区域キーから対応済み子区域分を差し引いて比較（合計・男女・年齢とも）
  • boundary：子区域の一部が対応不可、または差引結果が0以下 → 対象外（null＋注記）

件数

clean 1239／dup 13＋13／adj 11／adj-zero 2／boundary 30／非対応 140。対応値あり1234件、町丁合計387,717。未対応140件は住基独自の細分（第N区・団地・施設）で、国勢小地域（丁目より粗い）には対応単位が存在せず、構造的に対応不可。表記ゆれ（舘/館・ノ/之等）を吸収して2件を追加対応（長岡荘ほか）。

境界差の疑い候補（町丁単位）

  • docs/boundary_candidates.csv（python tools/list_boundary_candidates.py [閾値] で再生成、既定 |差|≥200）
  • 件数（対応1232町中、clean＝名称一致）: |差|≥200=25町、≥300=13町、≥400=6町、≥500=3町。
  • 親子重複（大字と丁目の二重計上）は0町（11地区は残差調整済み）。
  • サイトでは該当25町に CENSUS_FLAG="suspect" を付与し、選択時に「区域ずれ?」「国勢と区域がずれている可能性（要確認）」を表示。ランキングの注列は「区域ずれ?」。
  • 候補の原因は境界のズレか実差（施設・新築・時期差）のいずれかで、確定には国勢の町丁・字等境界データとの重ね合わせが必要。

主な修正例

  • 堀川南 本郷町：5055→子区域4959を除算→96（住基54、差-42）。修正前は差-5,001
  • 山室中部 町村：2532→子区域925を除算→1607（住基1593、差-14）
  • 新庄 経堂：1263→子区域1060を除算→203（住基348、差＋145、残差あり）
  • 東石金町・長江本町・不二越町・西中野町一丁目・向新庄町一丁目・新庄町一丁目ほか：同一名称の別地区に計上（近い方を採用）
  • 田畠・婦中町西本郷・八尾町奥田ほか30町：区域不一致のため対象外
  • 新庄北 新庄町：親区域が子区域の合計と一致し残余0 → 対象外
